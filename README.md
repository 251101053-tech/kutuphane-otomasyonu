
# Öğrenci Otomasyon Sistemi

C# Windows Forms ve Microsoft SQL Server kullanılarak geliştirilmiş masaüstü öğrenci bilgi yönetim sistemi.

## Özellikler
- **Kayıt Ekleme:** Öğrenci adı, soyadı ve okul numarası SQL Server veritabanına eklenir.
- **Kayıt Güncelleme:** Seçilen öğrencinin bilgileri ve okul numarası güncellenebilir.
- **Kayıt Silme:** Seçilen öğrenci kaydı veritabanından silinir.
- **Arama:** Öğrenci adına göre anlık filtreleme yapılır.
- **Listeleme:** Tüm kayıtlar DataGridView üzerinde dinamik olarak listelenir.

## Kullanılan Teknolojiler
- C# (.NET Framework)
- Windows Forms
- Microsoft SQL Server 2022
- ADO.NET (System.Data.SqlClient)
